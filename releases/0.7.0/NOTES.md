# Aion2DPSMeter 0.7.0

First numbered release. The earlier test kits (up to kit 7b) had no version number and show as 0.0.1; install this one by hand once, later versions update themselves.

New in 0.7.0:
- Class colours and the original class icons on the meter, the inspector and the fight details (⚙ "Class icons"; off shows a colour square).
- Size settings: an overlay size from 85 to 150 %, and a text size for the inspector and fight details windows.
- The inspector opens by itself when a new applicant arrives, without taking focus from the game, and looks them up right away. It can also open when you join a party (off by default), and "Look up automatically" looks up everyone even while it stays closed.
- "Grow upwards": the overlay keeps its bottom edge and grows up, for a strip parked at the bottom of the screen.
- The overlay remembers where you left it.
- Update check and one-click update (⚙ "Check for updates"). Beta updates are not signed yet: only install builds published by the owner.

Also in this build (from kit 6):
- Fight details window: skills, buffs, damage taken and the history of recent fights.
- Optional uptime column.
- Boss HP left in % with a thin HP bar in the header.
- A warning after a game patch when the meter cannot confirm the game's data format ("unverified protocol").
- abysslogs.com ranks on applicant and party cards (⚙ "abysslogs ranks").

Requirements: Windows 10 or 11 and Npcap.
